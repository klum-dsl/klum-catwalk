## Known upstream/release-line limitation

```text
./gradlew verifyDirectPublicBaseline
./gradlew :direct-schema:javadoc --rerun-tasks
```

Result: **expected failure, reproduced against public coordinates**. Both
paths stop in AnnoDocimal's `createClassStubs` / source-projection path with:

```text
Cannot classify referenced declaration containing '$':
com.blackbuild.klum.ast.runtime.KlumFactory.BuilderFactoryProvider
```

This is the intentionally exercised nested external signature seam of
AnnoDocimal #99. In the full graph it prevents
`createKlumDslSourceMirrors` from completing and blocks Javadoc before its
legacy paragraph/tag parsing path can execute. No workaround was added. The
separate AnnoDocimal #100 Javadoc-sensitive seam remains recorded but cannot
be independently reached while #99 blocks this one fixture.

The 4.0.0 historical product set is otherwise valid for this consumer: the
later `klum-ast-test-support` coordinate is not added. SC-1a remains the
separate owner for correcting KlumAST's line-unaware release/consumer resolver;
SC-2 remains the owner for candidate staging and rebinding.
