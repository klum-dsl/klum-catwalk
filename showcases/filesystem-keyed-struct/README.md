# Filesystem-organized documentation redirects

One small redirect catalog demonstrates two ways to construct the same keyed
KlumAST Model from YAML. The catalog uses the old URL path to look up a redirect
target. Its directory tree mirrors those old URLs, so the two `install`
directories under `guides` and `cli` represent distinct redirects.

The [Schema leaf](schema/README.md) contains both input forms, the executable
caller, the two generated JSON Schema artifacts, and the local verification.
